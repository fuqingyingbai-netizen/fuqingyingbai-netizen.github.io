# 左侧导航

常驻入口集中在首页、项目、学习记录、生涯规划与关于。资源、分类、标签和归档收进原生 details 的“更多浏览”，普通页面默认折叠；访问其中某页或子页时自动展开。所有页面和链接继续存在，菜单无需 JavaScript 也可展开和导航。

导航顺序和名称统一由 `_data/navigation.yml` 维护。`_includes/sidebar.html` 基于 Chirpy 7.6.0 的 MIT 模板，只替换导航部分，保留头像、主题切换和联系入口；升级主题时应对照上游模板核对这些部分。链接标记通过 `nav_parent` 与当前页在构建时生成，确保只有一个当前项；手机抽屉重新打开时也会展开并聚焦当前的次级入口。

手机布局检查继续覆盖展开后的末项可达、200% 字号、键盘焦点、抽屉遮罩与主题控件。导航专项检查覆盖五个常驻入口、原生折叠、次级页面和子页自动展开、无 JavaScript 与键盘操作。
