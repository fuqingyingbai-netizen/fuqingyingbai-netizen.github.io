# 首页、导航与阅读排版

- 首页保留姓名、已有身份、方向短句与项目/关于入口，放大姓名；RSS、规划等仍可从全站导航与页脚进入。
- 展开侧栏时，收起按钮在左侧栏内部；收起后，展开按钮保留在正文顶部。仍使用原有 `site-sidebar` 偏好，重新挂载按钮后恢复焦点，侧栏 inert 继续由统一的可访问性脚本管理。
- `_layouts/default.html` 基于 Chirpy v7.6.0 官方默认布局（MIT，仓库 LICENSE 保留版权声明）。保留内容重构、页脚、评论、搜索、弹窗目录与主题脚本插槽，只替换辅助栏插槽，并标记文章主列。
- 右侧按当前页面生成，使用普通 include 避免 include_cached 将首个页面的上下文复用于所有页面。项目索引取自 `_data/projects.json`，栏目入口由 `_data/sidebar.yml` 维护。文章目录优先展示，同主题文章仅按已有具体标签关联，并排除当前文章与隐藏文章。
- 分类页提供标签细查，标签页提供分类入口，归档页提供年份定位。`_layouts/archives.html` 同样基于 Chirpy 7.6.0，仅为既有年份标题补充稳定 ID，不改动旧文章链接。
- 资源、项目等页面的目录由渲染后的真实标题生成，沿用现有 ID；已有专题入口的学习记录、规划页不再重复目录。无脚本时不展示空目录，服务端生成的栏目入口仍可使用。移动端沿用主题目录弹窗。
- 阅读样式只影响文章页：标题/摘要区域、引导段落、章节分隔和正文行距。未改写已有文章内容、日期、链接或评论配置。

验收包括各栏目辅助栏内容差异、目录顺序及锚点、文章内容保留、评论和目录弹窗插槽、手机与200%文字、无脚本阅读，以及原有菜单、收起、历史返回与动效回归。
