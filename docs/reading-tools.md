# 阅读、搜索和评论反馈

- Mermaid 完成渲染后，流程图按 SVG 原始尺寸展示在可滚动区域内，避免窄屏等比缩成几像素文字。放大入口使用原生 dialog；支持缩放、适应窗口、Escape、键盘焦点和返回入口。弹窗移动同一张 SVG，不复制其 ID；主题重绘后重新应用尺寸。JavaScript 不可用时保留原始流程代码。
- 搜索仍使用 Jekyll 生成的本地索引和 Chirpy 的打开、取消控件。结果按标题、标签、分类、正文匹配排序；项目用 canonical_url 与已有说明或文章合并，保留仓库名称等搜索别名。文本通过 DOM textContent 渲染，中文输入结束后再检索；空查询、空结果和索引读取失败有对应反馈。
- 评论客户端固定为 Waline 3.16.1，并按需加载。脚本、样式及 MIT 许可保存在 assets/third-party/waline/3.16.1，随网站发布，消除单独的 CDN 依赖；客户端发行文件不修改。适配其原生列表状态，区分读取中、空列表、已有评论与失败；错误重试点击客户端原生“重新读取评论”操作，保留表单实例与未提交内容。样式和模块加载失败时可重试，重新加载模块使用独立查询参数避免浏览器缓存失败。
- 客户端适配不改变评论路径、提交、审核、限频或后端配置。阅读检查使用站内固定版本客户端并模拟只读 API，覆盖网络中断、HTTP 错误、业务错误、无效 JSON 及资源加载失败。独立 check_comment_submit.cjs 使用同一个客户端模拟提交网络失败、限频、重新提交、成功与待审核；所有测试 POST 均被拦截，不向真实服务提交留言。
- 手机评论表单的字数、登录、提交一栏允许换行，避免 320px 宽度、200% 文字下按钮被推出屏幕。提交按钮保持至少 44px 高，不裁切内容或缩小字号。
- 2026-10-20 排查时，本机直连 vercel.app 评论域名解析到错误 IP，通过系统代理读取和手机 WebKit 在独立测试路径提交均成功。这属于评论 API 地址的网络可达性问题；站内托管客户端不能修复 API 的 DNS。恢复手机直连需要给现有服务绑定可管理的自定义域名，并实测手机网络。保留既有数据库与评论路径，不能将代理凭据、管理员令牌或数据库连接放到前端。
- 构建后运行 tools/check_reading_tools.cjs；与既有手机布局、内容链接、搜索合同、评论模式和动效检查一起运行。
