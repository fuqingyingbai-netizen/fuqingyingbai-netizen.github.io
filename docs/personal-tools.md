# 续读、项目筛选和规划备份

- 文章阅读位置按原文章路径保存在 localStorage。首次打开不记录初始滚动；读者滚动、使用阅读按键或章节链接后才保存。返回时提供继续与清除操作，不自动跳转；带章节锚点的链接优先，读到末尾后清除位置。记录仅包含章节 ID、相对位置与进度，不发送到服务器。
- 项目筛选使用 `_data/projects.json` 的既有分组和标签。`tools/sync_projects.py` 同时生成卡片筛选数据和分组容器；项目锚点与搜索地址不变。筛选条件写入 group/tag 查询参数，支持复制地址、前进后退与无结果提示；打开被筛选隐藏的项目锚点时清除冲突条件。关闭 JavaScript 时仍展示所有项目。
- 规划沿用原本的 `career-planner:<planId>:v1` 本地记录。Markdown 导出继续可用；JSON 备份包含 format、version、planId、exportedAt 和 data。恢复前检查 256 KB 文件限制、版本、计划、任务 ID、周 ID 与复盘长度，任何错误都不改当前记录。先显示摘要，确认后整体替换；再次编辑前可撤销。复盘只赋值给 textarea，不作为 HTML 执行。备份在浏览器本地读取，不上传、写入仓库或纳入周总结。
- 浏览器禁止存储时，文章照常阅读；规划可在本页恢复和重新下载，但会明确说明未能保存。记录不自动跨设备同步，备份需自行保管。
- `tools/check_personal_tools.cjs` 使用匿名浏览器与合成记录检查续读、筛选地址与旧锚点、备份往返、取消、撤销、异常文件、存储受限和窄屏放大。所有跨站请求被拦截，不操作站主真实浏览器记录。
