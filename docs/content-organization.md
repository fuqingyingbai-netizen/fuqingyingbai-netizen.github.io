# 内容组织与分享

- 分类描述记录形式：学习笔记、项目实践、随笔、每周总结。电商问数复盘归入项目实践；显式保留其原有 permalink，评论仍使用同一路径。生涯规划专题保留。
- 常用主题由 `_data/content_navigation.yml` 维护，用于标签页和分类页右栏。原有标签没有删除，全部标签可通过原生 details 展开，14 个旧标签链接继续生成。
- 学习记录页把项目复盘与随笔分开；原有 `#learning`、`#practice`、`#weekly` 保留，新增 `#essays`。周总结仍按原有分类自动归档，定时与公开素材规则不变。
- 项目卡片仍由 `_data/projects.json` 和 `tools/sync_projects.py` 生成。实时信息只展示有效日期、正数星标及标签中未出现的语言；缺失数据不显示占位字段。个人与 Fork 分组不变。
- 各栏目提供显式 description。栏目分享图片沿用站内 1200×630 封面，由 tabs defaults 统一指定路径、尺寸与替代文字；项目说明继续使用各自的图片。
- 关于页仅依据已有公开介绍、项目和生涯规划整理。项目页新增片段链接固定到公开仓库提交，注明配置摘录、返回逻辑与试用输入的性质，不宣称已运行或实测。
- 本轮不改项目同步、周总结和评论服务的部署配置。
